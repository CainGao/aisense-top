# AI Sense — The AI Tools Directory

> 🤖 Discover the best AI tools. Updated daily.

## About

AI Sense is a curated AI tools directory targeting the global market. We help creators, developers, and professionals find the perfect AI tools for their workflows.

## Tech Stack

- Pure HTML5 + CSS3 — zero dependencies
- Dark theme, responsive design
- GitHub Pages deployment
- Auto-updated daily by OpenClaw cron (01:00 CST)

## Revenue Model

- 🔗 Affiliate commissions (up to 30%)
- 📺 Ad revenue (Google AdSense)
- 💎 Featured listings ($99-499/mo)
- 📧 Newsletter sponsorships
